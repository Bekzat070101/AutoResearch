## 0. 一页结论
- 主价值（§1D）：AI 把技能和知识变便宜之后，稀缺的是「你凭什么脱颖而出」。启研是学生的定位与博弈层：盘点自己的边 → 看清每个组 / 机会 / 子领域的需求、供给与势头 → 选一个不拥挤且自己有边的生态位 → 写一句有证据的定位陈述 → 选稀缺的信号，按时机和组合下注。「用过启研」= 更会给自己做战略。
- 降本引擎（§1C）：读 → 比 → 问 → 提 → 试（阅读卡、矩阵、问题阶梯、提案画布、最小测试），引文必须能在原文定位。它是学生现在愿意付钱的部分，也是边的原材料：定位陈述里的「因为」只能引用这些已证明的作品。
- 只有平台才有的数据（护城河）：多少同类学生在瞄准同一个组 / 子领域（聚合、k ≥ 5、按档显示）、联系结果、边的组合稀有度；外加核对过的机会数据和学长学姐核对的领域工具包。
- 节奏：每日 ≤10 分钟（分拣 arXiv 新论文练品味、看雷达变化、一次定位微调）；每周做重活；临近截止冲刺。不做连胜、排行、徽章。
- 双窗口：学生在另一个窗口用自己的 Agent。启研导出带标准与诚信规则的「交给你的 Agent」简报，收回产物 + 决策日志（可附真实轨迹）；评阅看判断，不只看产物。对外一句话：「我们让你的 Agent 更会做研究，让你的定位有证据、有数据。」
- 不是聊天框：没有任何「问 AI」入口；我们的模型只做八件受约束的活；关掉模型，每个主界面照样能用。
- IA：今日 / 定位 / 研读 / 机会 / 作品 五个标签；账本在「我」菜单里；工作台是全屏模式。
- 滩头：有野心、缺人脉的北大大一大二（负责人已确认）。
- 落地：单人 + Agent 1–3 天出第一条纵切片（边清单 → 竞争地图 → 定位陈述，引用一张过线阅读卡），约一周出 v1；需要人核对的数据从第 1 天并行开始。
- 先验证：竞争地图能否让选择转向更不拥挤、更贴合自己边的位置，同时不制造新的扎堆；这里写出的定位陈述能否在目标读者盲评中胜出；每日情报能否坚持；「Agent 单独」对「Agent + 启研」。

## 1. 我们到底在做什么
### 1.1 问题
- 用户：北大（先北大，后同类高校）大一大二里「有野心、已经在卷」的那部分人：想尽早进课题组、拿本研 / 大创 / 挑战杯立项或奖项、有第一份署名或一封分量足的推荐信，为保研、直博、出国积累站得住的经历；他们读小红书 / 知乎 / B 站的科研帖、套磁、问学长学姐、同时用境内外的生成式 AI（Xie, Li & Cheng, 2025），一部分会付钱给科研辅导或背景提升机构。
- 工作（JTBD）：「在人人都有同一个 Agent、人人都在卷同一条路的池子里，找到我能赢的位置，并拿出别人认的证据。」子工作：①认清自己的边 ②看清赛场（哪里拥挤、哪里有名额、什么在升温）③选位置并说清「为什么是我」④用最低成本把位置做实（读、比、问、提、试）⑤在对的时间、用稀缺的信号出手 ⑥被真人接住，产品退场。
- 背景事实：一项覆盖 39 所高校的调查中，与老师一起做研究的本科生占 17.84%，「双一流」高校学生参与科研相关活动的比例为 38.14%，第一代大学生参与更少（Ke et al., 2022）；本科生科研是高影响力教育实践（Kuh, 2008），越早接触研究，完成理工科学位的可能越高（Rodenbusch et al., 2016）。
- 北大节奏：「本科生科研训练」面向大二及「学习成绩优秀、学术志向明确」的大一，有「导师公开题目（每题最多一名学生）」和「自主联系导师」两条路；2025 年 6 月中下旬截止申请、12 月中期、次年 10 月结题（北京大学教务部，2025）。10 月入学的大一想走本研，春季就要有导师点头。
### 1.2 一学期后的成功（可观测）
- 一份过了规则检查、经目标读者看过的定位陈述，「因为」部分全部由已证明条目支撑。
- 一张过线的提案画布 + 一件过线的最小测试（版本可追溯、附 AI 使用声明与决策日志）。
- 一组 ≤3 个分好「冲 / 稳 / 保」的目标，至少一个走完「准备 → 联系 → 有结果」。
- 校准：自估就绪度与外部评审的差距缩小。进组或立项是期望结果，不承诺必然发生，也不作唯一标准，否则会诱导造假和刷量（§12）。
### 1.3 不为谁
- 想买论文、挂名、代写的人：拒绝并写在首页；只要书单和泛泛建议的人：通用 Agent 已经够了；已在组里有稳定导师的人：只在「学长学姐」一侧接住（§5.8）。
### 1.4 同意 / 不同意
- 同意负责人的重构：证据显示生成式 AI 对新手帮助最大、压缩了个体差距（Brynjolfsson, Li & Raymond, 2025; Noy & Zhang, 2023），同时让个人作品更有新意、群体作品更趋同（Doshi & Hauser, 2024）。人人用同一个 Agent，「会做」不再稀缺，「站在哪里、凭什么」才稀缺。
- 补一处修正：AI 压低的是获取知识的成本，不是「被证明的能力」「判断问题的品味」和「可信信号」的成本。没有证据的定位就是机构在卖的包装。所以 §1D 必须绑在 §1C 的作品和账本上——这条线也是我们和机构的分界。
- 同意滩头：有野心但缺人脉的人受信息约束最强；对高分低收入高中生的信息干预曾改变他们的申请组合（Hoxby & Turner, 2013）。
- 「每天用」只落在 ≤10 分钟的情报层；重活按周；北极星不是日活。课程约束（每次交互落到一件具体的事、不编造、面向大一大二、先展示结果再改代码）全部保留。

## 1A. 市场与竞争：我们凭什么赢
### 1A.1 细分

| 细分 | 现在怎么做 | 最痛的点 | 我们给的 | 优先级 |
| --- | --- | --- | --- | --- |
| S1 有野心、缺人脉（第一代大学生、无直系学长、非一线城市出身） | 小红书 / 知乎 + DeepSeek + 群发套磁，考虑机构 | 不知道哪里拥挤哪里有名额、说不清「为什么是我」、读不动论文 | 竞争地图 + 定位陈述 + 工具包 + 敲门砖 | 滩头 |
| S2 有野心、有人脉 | 学长学姐 + 自学 | 和身边人挤同一条路、信号同质 | 定位层 + 每日情报 + 作品集 | 第二 |
| S3 已进组 | 导师 | 少 | 成为供给侧（组卡、工具包核对、分拣参照） | 供给侧 |
| S4 还在摇摆 | 观望 | 不知道适不适合 | 「先摸清方向」目标 | 不为其设计主流程 |

### 1A.2 替代品

| 替代 | 它弱在 | 我们为什么赢 |
| --- | --- | --- |
| 学长学姐口口相传 | 看运气（弱关系决定你接触到谁，Granovetter, 1973）、过时、只有个案 | 把他们的知识结构化成组卡与工具包，并把人接进来；个案变成聚合的需求与结果数据 |
| 小红书 / 知乎 / B 站 | 幸存者偏差、不针对你、夹带机构广告，而且人人看同一篇帖子——帖子本身制造扎堆 | 每条机会有来源与核对日期；拥挤度是数据不是传闻 |
| 学生自己的 Agent | 会编（GPT-4 生成的参考文献 18% 是编造的，Walters & Wilder, 2023）；没有需求与结果数据；同一池子里的人问「我的独特角度是什么」会得到相似的答案（Doshi & Hauser, 2024）；替你思考，撤掉后更差（Bastani et al., 2025） | 不和它比：给它核对过的输入和标准，给它参与的产出以公信力（§1B.3） |
| 付费背景提升 / 规划机构 | 定位靠话术、背景靠买；「论文工厂」用 AI 批量代写（新京报, 2024），背景提升被报道为可花钱买的「加分项」（新浪财经, 2022）；代写属学位法第三十七条撤销学位情形 | 定位有需求数据和已证明条目支撑；不代写；结果属于自己 |
| 学校项目（本研、大创、本科生导师） | 一年一个窗口、要先有导师、通知分散 | 做它们的前置坡道：时机提醒 + 同一套作品复用到申请 |
| 树洞 / 院系通知 | 噪音大、搜不到、不可核对 | 结构化 + 核对 + 雷达变化 |

### 1A.3 楔子：「去哪、凭什么」
- 定义：在竞争地图上看一个组的需求、供给与势头 → 用边清单找自己能赢的生态位 → 写定位陈述 → 用敲门砖把它做实（读该组 2–3 篇论文写阅读卡 → 小矩阵 → 提案画布 → 最小测试）→ 套磁准备台 → 看板。
- 为什么：这群人最常问的就是「我该去哪、他们凭什么选我」；答案需要只有平台才有的聚合数据；它是机构卖得最贵的「规划」的有证据版本；同一份定位与作品可复用到本研、大创、推免材料。
### 1A.4 增长回路
1. 地图数据回路：用户越多 → 需求与结果数据越准 → 地图越有用 → 用户越多（经典数据网络效应；覆盖不足时如实显示「数据不足」）。
2. 作品回路：学生在套磁信、申请、简历里放作品集链接（首行就是定位陈述）→ 同学与老师看到 → 注册。
3. 小组回路：小组 4–6 人才开张 → 学生拉同专业同学 → 每周交付与互评留住人。
4. 学长学姐回路：进组用户转为供给侧，写组卡、核对工具包、做每日分拣参照 → 低年级因此而来 → 他们进组后再成为学长学姐。
5. 内容回路：经同意，把匿名「从零到进组」轨迹（定位陈述 + 时间线 + 节点）做成可分享卡片发到小红书 / 知乎——带凭据的版本。
6. 简报回路：导出的 `AGENTS.md` / `SKILL.md` 头部写明「按启研标准 vX 生成」，随学生仓库与转发传播。
### 1A.5 护城河
- 会积累：需求与拥挤度数据、联系结果数据、组合稀有度（只能从大量用户的目标与边聚合）；核对过并持续刷新的机会数据；学长学姐核对、带版本的领域工具包；与老师和博士生共签的标准；校内网络（最小网络是「一个院系 × 一个方向」，Chen, 2021）；第三方持有的账本与作品历史（Spence, 1973; Donath, 2007）。
- 不积累、不投入：模型措辞、书单、选题点子、概念讲解、润色。
### 1A.6 最危险的假设（按「错了就要重来」排序）
- R1 竞争地图 + 边清单会让学生把目标转向更不拥挤、更贴合自己边的位置，而且不会制造新的扎堆。
- R2 在这里写出的定位陈述，在目标读者盲评中比普通自我介绍更有区分度、更可信，也胜过学生用自己的 Agent 改写的版本。
- R3 每日情报（≤10 分钟）能坚持，并让学生的分拣与学长学姐的判断逐渐接近。
- R4 「Agent + 启研」在事实正确、问题质量、是不是自己想的上胜过「Agent 单独」。
- R5 需求数据能在滩头（一个院系 × 一个方向）达到 k 阈值，且不被虚报目标操纵。
- R6 学长学姐愿意供给（组卡、工具包核对、分拣参照）。
- R7 机会数据与工具包的维护成本可承受。
- 后期可选：老师是否看重作品集与过程证据（不再作为门槛）。
### 1A.7 漏斗指标
- 激活：注册 7 天内完成边清单 + 一张过线阅读卡 + 一份引用了该卡的定位陈述草稿。
- 留存：每周分拣天数；第 1–4 周每周至少交一次重活的比例。北极星：每周过评阅的证据数（含定位陈述的更新）。
- 推荐：每个激活用户带来的激活用户；作品集外链打开数；结果：联系 → 回复 → 面谈 → 进组 / 立项（自报 + 可选凭据）。

## 1B. 为什么不是一个聊天框 / 通用 Agent 做不到什么
### 1B.1 测试与定位
- 测试：一个每月付约 20 美元、配了像样 harness 的学生已经能拿到科研建议、阅读清单、项目点子和单篇反馈。凡是能这样复现的都不是我们的价值。
- 定位：不替代学生的 Agent，而是让它更会做研究，并让学生的定位与作品可信。Agent 越能干，学生越容易把读和想外包（对 AI 信心越高、批判性思考越少，Lee et al., 2025）；我们的结构让学生自己想，并能证明是自己想的。
- 我们仍要自己的模型，因为裁判必须独立于选手的器械：同一把尺子、规则为上限、引文逐字核对，结果才有公信力。
### 1B.2 结构件

| 结构件 | 通用 Agent 为什么不能便宜地重建 | 护城河 | 现有地基 |
| --- | --- | --- | --- |
| 需求、拥挤度与结果数据 | 公开网络上不存在，只能从大量用户的目标、边与看板聚合 | 规模越大越准，后来者拿不到 | 无，新建 |
| 核对过、持续刷新的机会数据（组、本研 / 大创 / 竞赛、北大课程、截止） | 每次临时检索，不知道哪些页面过期、今年收不收，还会编 | 来源清单 + 刷新脚本 + 人工核对，成本被所有用户摊薄 | 任务 3 的 24 个来源、`check_sources.py`、北大搜课 |
| 领域工具包（§1C.5） | 现场「学」一个子领域再讲，每次不同、没人核对 | 一次建好、学长学姐核对、带版本、共用 | 任务 4 路径的「依据」与链接核对纪律 |
| 账本、研读与作品历史、决策日志 | Agent 的「记忆」是它自己的摘要，不是第三方核对过的证据 | 带时间戳、版本、评阅出处与引文定位，由第三方持有 | `UserFact`（证据、来源、软删）、任务 3 评阅写回 |
| 标准与工作流（卡、矩阵、问题、画布、定位陈述、六步过关标准） | 每次给的标准不同、没人签认、会被说服给高分 | 共签、带版本；规则为上限、引文逐字核对 | 任务 4「做完怎样算过了」、`submission.py` |
| 社会与机构结构（小组、学长学姐、老师触点、本研通道） | 没有同校的人，接不进学校流程 | 校内网络效应 | 无，新建 |
| 一眼可读的界面（竞争地图、矩阵、时间线、看板、作品集） | 线性文本，状态要靠追问 | 设计可抄，数据抄不走 | 方向树、主干六步、今日卡 |

- 不变式：`LLM_API_KEY` 为空时每个主界面都能完成主任务（现有代码已做到失败回退规则，写成测试并作为 PR 必过项）。文本输入只做结构化采集；唯一和 AI 有关的按钮是「交给你的 Agent」，它导出文件，不开对话。
- 明确砍掉：旧分工里的「问导师」聊天页（TASK_ASSIGNMENTS §4）、画像的对话气泡形态、任何「问 AI / AI 帮你写 / AI 帮你找项目 / AI 帮你定位」按钮。
### 1B.3 双窗口：学生自己的 Agent 是手，启研是地图、标准和账本
- 设计假设（负责人）：学生会在另一个窗口主动用自己的 Agent，禁止不了也不该禁止。课程就是这样训练的：isse-labs 实验目录附 `AGENTS.md`，要求 Agent「思考题必须先让用户回答」「不得替用户新增其没有表达过的核心观点」，并由学生把真实对话粘贴进 `AGENT_TRACE.md`，不得用总结冒充（isse-labs `lab2/AGENTS.md` 第 11、12、15 条）。我们把同一模式搬进科研训练。
- 分工：启研是记录系统（地图、标准、工具包、机会、账本、作品集）加裁判（引文核对、按标准评阅、决策日志核对）；学生的 Agent 是工作台（跑代码、查报错、解释概念、对草稿提批评与问题）。
- 交出去：每个动作都有「交给你的 Agent」，由标准注册表生成简报：仓库型 Agent 下载 `AGENTS.md`（技能型 harness 用 `SKILL.md`），网页型复制纯文本。固定七段：交什么 · 标准条目与版本 · 引文规则（给页码、逐字、找不到写「未找到」）· 诚信规则（不替学生写主张、「我会改什么」、矩阵论证、问题、画布、定位陈述；只批评与提问；思考题先让学生答）· 资源（工具包论文、数据集）· 交回格式（建议逐条编号）· 轨迹要求（学生复制真实对话）。
- 交回来：「导入」接受三样：学生的产物（填进固定栏）、决策日志（编号 / Agent 建议 / 采纳·修改·拒绝 / 理由）、可选真实轨迹（粘贴或分享链接）；导入时剔除疑似密钥与个人信息。
- 状态：Agent 内容先标「Agent · 未核实」；引文定位通过后「已核实」，失败标红「原文里找不到」并阻断过线；学生逐条表态后才能交。
- 把「会用 Agent 做研究」当成可核对的技能：要批评不要答案、核引文、记决策；工具包附学长学姐的示范轨迹与批注，像示范卡一样渐退。
- 以后再做：只读 MCP 接口，经学生授权让其 Agent 读工具包与机会数据（可默认开）和账本（按类别授权、可撤销、访问留日志），不开放写入；授权页写明数据会进入第三方模型服务商（§12）。

## 1C. 研究思维层：降本引擎 + 边的原材料
### 1C.1 立场
- 重新定位：读 → 比 → 问 → 提 → 试 不是产品的终点，而是两件事：①降本——把「读懂一个小领域、提出一个站得住的问题」的时间成本压到大一学生付得起，这是学生现在愿意付钱的部分；②原材料——每张过线卡、每个矩阵格子、每个最小测试都是一条已证明条目，定位陈述的「因为」只能从这里引用。
- 依据：结构化精读一手文献能在一学期内提高本科低年级读文献的自评能力与对科研过程的理解（C.R.E.A.T.E.：Hoskins, Stevens & Nehm, 2007; Hoskins, Lopatto & Stevens, 2011）；「找问题」是与「解问题」不同的能力（Getzels & Csikszentmihalyi, 1976）；把专家思考显性化并逐步撤掉支架是认知学徒制的核心（Collins, Brown & Holum, 1991）。
- 我们的模型不替学生读、填、出题，只对照原文核对、按规则发问；有护栏、不给答案的 LLM 助手可在真实课堂大规模部署（Kazemitabaar et al., 2024）。学生的 Agent 在简报约束下做同样的事，产出按 §1B.3 处理。
### 1C.2 阅读卡（每篇一张，固定形状）
- 字段：主张（自己的话 + 作者原句一条作锚点）· 证据（图 / 表 / 数字）· 方法 · 假设（作者默认但未检验的事）· 局限（**必须引作者原文**）· 我会改什么（一句，学生自己的）。
- 规则：主张、证据、局限三栏的引文必须在论文文本里逐字找得到并带位置——沿用 `submission.py` 对 zip 评阅已执行的规则；规范化后匹配（去连字符、统一空白与全半角），自动定位失败可手填页码，标「未自动定位」，不进作品集。
- 模型核对只输出「卡上那句 + 原文那句 + 位置 + 一个问题」，例如卡写「多语言上都更好」、原文 §5 写「only evaluate on English」。
### 1C.3 综合矩阵（论文 × 维度）
- 维度由工具包给出（数据 / 任务、方法、对象、指标、结果方向、作者自述局限、关键假设），学生可增列；格子只由学生自己的卡填入，模型从不填格子。
- 缺口自己显形：空格 = 没人做或你没读到；冲突格 = 同一指标结果方向相反；整列为空 = 大家都没检验的假设。表格式组织文献是 Garrard 矩阵法的核心（Garrard, 2020）。
- 防止机械找空格：Alvesson & Sandberg (2011) 批评「找缺口」只是在既有框架里补洞，主张挑战文献背后的假设。学生选中格子时必须写三句：①这里被默认了什么 ②不成立会怎样 ③谁会在乎。对低年级，找缺口是合法起点，「假设」一列是通往问题化的台阶。
### 1C.4 问题阶梯与提案画布
- 问题阶梯：「我在研究 X，因为我想弄清 Y，以便让读者理解 Z」（Booth et al., 2016）；标准：具体、一学期内可行、写明什么结果会让你改主意（Platt, 1964）、指向矩阵至少一格。
- 提案画布（一页）：问题 · 已知（≥3 张自己的卡）· 缺什么（矩阵格子 + 三句论证）· 最小测试（≤2 周）· 预期与证伪 · 需要谁帮（人，不是 AI）；形式参照 Heilmeier 问题清单（DARPA）。任务 3 的公开项目降级为「最小测试」的候选试验场。
- 画布评阅三层：规则（结构完整、引用存在）→ 模型核对（与卡一致、证伪条件可观测）→ 学长学姐或助教评「值不值得做」（模型不判断意义）。
### 1C.5 领域工具包（离线建、人核对、共用、带版本）
- 内容：经典论文与阅读顺序 · 标准数据集与基准 · 开放问题（**只收论文局限 / 未来工作段的原文**，带出处）· 2–3 张专家批注的示范卡与一张示范矩阵 · 矩阵维度模板 · 对应的 arXiv 分类与关键词（每日分拣的来源）。
- 生产：团队按模板起草 → 一位该方向的学长学姐或助教逐条核对 → 发布带版本与核对人 → 每学期复核。模型可帮做引文定位与链接检查，不决定收什么。开放问题列表同时是 §1D 生态位的候选池。
### 1C.6 示范与渐退
- 示范卡（全填 + 批注）→ 提示卡（部分预填 + 位置提示）→ 独立卡；矩阵和画布同样三档（Renkl & Atkinson, 2003）；会了就撤，已经会的人再看示范反而有害（Kalyuga et al., 2003）。某字段连续两张卡过线即撤该字段提示。
### 1C.7 文献从哪来
- arXiv、GitHub 直接链接，服务器按 arXiv 编号取 PDF；订阅库论文由学生经北大图书馆（VPN / CARSI）下载后上传，只供本人使用；中国科技论文在线可免费下载；Semantic Scholar / OpenAlex 用于元数据与引用数。工具包只存元数据和短引文并指明出处（著作权法第二十四条）。

## 1D. 定位与博弈层：用自己的边差异化（主价值）
### 1D.1 为什么是主价值
- 稀缺性转移：技能与知识变便宜、产出趋同（§1.4 的证据），于是「同样的努力放在同样的位置」回报下降。大家挤同一条路是在比「谁更好」，接近零和；选不同的位置是在比「谁不同」（Porter, 1996 区分运营效率与战略定位）。同一池子里竞争者越多，人的竞争动机越低（N 效应，Garcia & Tor, 2009）。差异化不是道德劝说，而是拥挤市场里更划算的策略——它恰好也减少正面对撞。
- 组合本身是边：高影响论文多是在常规知识主体里嵌入少量非常规组合（Uzzi et al., 2013）；冒险策略更常被忽视，也更可能高影响（Foster, Rzhetsky & Evans, 2015）——所以要组合下注，不全押一处。
- 「用过启研」应留下六个可迁移的动作：盘点边 · 读赛场 · 选生态位 · 写有证据的定位 · 选稀缺信号 · 按时机与组合下注。每个都是一个结构化对象，毕业后也能用。
### 1D.2 边清单（结构化采集，不聊天）
- 七类：①已证明技能（从账本自动导入，不可手改）②课程组合（北大搜课的真实课程，跨院系组合高亮）③语言（含方言、少数民族语言、小语种）④背景与经历（地区、家庭行业、竞赛、实习、兴趣社群）⑤数据或社群接入（能接触到的人群、机构、语料、设备）⑥时间（每周小时、寒暑假）⑦工具（软件、算力）。
- 每条标「已证明 / 自述」；自述可通过上传凭据或完成一个小动作转为已证明。我们的模型只从学生贴的简历和链接里抽取自述条目，不推断「你的边是什么」。
- 组合稀有度（规则计算）：在瞄准同一子领域的用户里，拥有相同两两组合的人数，k ≥ 5 才计数，显示为「罕见 / 少见 / 常见」；覆盖不足显示「数据不足」。
### 1D.3 竞争地图（组 / 机会 / 子领域）
- 需求：本平台用户中把它设为活跃目标、且已为它交过至少一件过线作品的人数（只数有投入的目标，防止虚报目标吓退别人）；按周更新、滞后一周、按档显示（冷 / 温 / 热）；该院系 × 方向的用户覆盖不足时显示「数据不足」，以免把「平台人少」误读成「冷门」。
- 供给：已知名额——本研公开题目数（每题限一名学生）、组卡里学长学姐填的「本学期收几名本科生」、竞赛名额；未知写未知并给获取路径。
- 势头：工具包对应的 arXiv 分类与关键词下近 12 个月新论文数的变化、开放问题数；只作修正，不单独决定。
- 拥挤度 = 需求档位 ÷ 已知供给，势头修正；公式公开，每个格子可点开看依据。只给学生看，组和老师看不到需求数据（v1 决定）。
### 1D.4 生态位与定位陈述
- 候选生态位 = 工具包开放问题（原文）× 学生的边 × 拥挤度不高，规则求交集列成小表；按学生选的排序键排序，不给「最佳」。
- 定位陈述：「我是能做 X 的人，因为 Y。」X 必须指向一个开放问题或矩阵格子；Y 必须引用 ≥1 条已证明条目（自述可出现，标「待证明」）；旁边显示该生态位的拥挤度与组合稀有度。
- 规则检查只指出不打分：X 是否具体（点名对象、方法、数据）；Y 是否有已证明条目；Y 是否在该生态位池子里「常见」（常见则提示「这个理由在这里很常见，什么是别人没有的？」）；是否与画布的问题一致。我们的模型只核对陈述与账本、卡、画布有没有矛盾，不替学生写、不推荐生态位。
- 去处：作品集首行、套磁准备台第①格、本研申请「研究基础」段。新增已证明条目时提示「这条能不能强化你的 Y？」（每日微调的来源之一）。
### 1D.5 信号设计
- 每类目标一张信号表：信号 × 在该目标申请池里常不常见 × 造假成本 × 与目标的相关性；来源是标准注册表、组卡和平台聚合（k ≥ 5）。

| 目标：进某个组 | 常见度 | 造假成本 | 相关性 |
| --- | --- | --- | --- |
| 对该组论文的阅读卡 + 画布 + 最小测试 + 决策日志 | 低 | 高 | 高 |
| 竞赛奖项 | 看池子（平台聚合后标注） | 中 | 中 |
| 绩点 | 在北大申请池里普遍高 | 低（已被学校认证，但不区分） | 低 |
| 「热爱科研、学习能力强」 | 普遍 | 零 | 无 |

- 凭证膨胀提示：某信号在瞄准同一目标的用户中变常见时，标「在这个池子里常见」，不建议再加码（Collins, 1979；分离均衡需要成本差异，Spence, 1973）。
- 稀缺即可信：经济学博士就业市场的信号机制只允许每人向两个雇主表达特别兴趣（Coles et al., 2010）；约会网站实验中数量有限的「玫瑰」提高了邀约被接受的概率（Lee & Niederle, 2015）。我们的「同时联系 ≤3 个组」因此是功能而非限制：套磁准备台允许写明「这是我本学期联系的三个组之一」。
### 1D.6 时机
- 每个目标的时间线画三类节点：官方节点（如本研 6 月申请）、平台观测到的需求高峰（数据够时）、学生自己的就绪点。建议「比高峰早 4–8 周，且已有 1 件过线作品」，不鼓励无限提前：匹配市场里人人抢跑会让整个市场提前「解体」，对所有人都更差（Roth & Xing, 1994）。
### 1D.7 下注组合
- 同时最多 3 个活跃目标，标「冲 / 稳 / 保」：冲 = 拥挤或门槛高、边部分匹配；稳 = 边匹配、拥挤中等；保 = 拥挤低或制度化通道（本研公开题目、助教项目）。申请组合是投资组合问题（Chade, Lewis & Smith, 2014）。
- 规则检查：三个都是「冲」提示风险；三个都在同一热门子领域提示相关性过高；建议先用「保」拿到第一件过线作品和第一位推荐人再冲。目标结束后填结果与一句原因，聚合（k ≥ 5）后回写地图。
### 1D.8 平台对自己的影响负责
- 少数派博弈：如果所有人都按同一个「最不拥挤」信号行动，冷门会瞬间变热（Arthur, 1994 的酒吧问题）；显示热度会放大羊群与不可预测性（Salganik, Dodds & Watts, 2006; Bikhchandani, Hirshleifer & Welch, 1992）。
- 对策：①不给「最冷门」排行，拥挤度永远与学生自己的边并排出现；②拥堵感知：同一生态位每周作为候选出现在同类学生面前的次数设上限，超出轮换；③档位而非精确数，滞后一周；④只数有投入的目标；⑤k ≥ 5 与覆盖阈值；⑥上线后每周看目标分布的集中度，变集中就收紧（§15 T1）。

## 3. 设计原则
1. **先选位置，再加努力。** 依据：战略定位与运营效率之分（Porter, 1996）、N 效应（Garcia & Tor, 2009）、非常规组合（Uzzi et al., 2013）。后果：定位层是主导航的第二个标签；今日的主动作必须说明它服务哪个目标与生态位。
2. **定位必须有证据。** 依据：信号理论（Spence, 1973）、难伪造的信号（Donath, 2007）、招聘方从活动痕迹推断能力（Marlow & Dabbish, 2013）。后果：定位陈述的「因为」只能引用已证明条目；作品集展示版本、引文定位、决策日志。
3. **平台对自己的影响负责。** 依据：少数派博弈（Arthur, 1994）、社会影响放大不平等（Salganik et al., 2006）、抢跑导致市场解体（Roth & Xing, 1994）。后果：拥挤度按档、滞后、与边并排、拥堵感知轮换、不给冷门排行。
4. **学生思考，Agent 做手，系统核对。** 依据：无护栏的 LLM 辅助撤掉后更差（Bastani et al., 2025）；认知强制减少过度依赖（Buçinca et al., 2021）。后果：卡的主张、矩阵论证、问题、画布、定位陈述由学生写；我们的模型只输出「位置 + 原文 + 问题」。
5. **证据可定位，查不到就说查不到。** 依据：LLM 引文编造（Walters & Wilder, 2023）；可审查的学习者模型（Bull & Kay, 2007）；人–AI 交互准则（Amershi et al., 2019）。后果：每个建议挂 ≤3 个证据片；未知显示「未知」并给获取路径。
6. **标准先公开，过线可改。** 依据：Sadler (1989)；Panadero & Jonsson (2013)；掌握目标结构（Ames, 1992）。后果：动手前看标准；结果是「过线 / 未过线 + 改哪一处」；历史可见。
7. **示范在前，支架渐退。** 依据：认知学徒制（Collins, Brown & Holum, 1991）、支架（Wood, Bruner & Ross, 1976）、Renkl & Atkinson (2003)、Kalyuga et al. (2003)。后果：示范 → 提示 → 独立，会了就撤。
8. **节奏分层，诚实校准。** 依据：执行意图（Gollwitzer & Sheeran, 2006）、习惯形成（Lally et al., 2010）、过度自信导致学得不够（Dunlosky & Rawson, 2012）。后果：每日 ≤10 分钟、每周重活；时间线写依据与不确定；数据不够写「数据不足」。
9. **对事不对人，只和标准比，交给真人。** 依据：指向自我的反馈削弱表现（Kluger & DeNisi, 1996）；排行与徽章在一学期内降低内在动机（Hanus & Fox, 2015）；本科科研的收益主要来自真实的指导关系（Thiry & Laursen, 2011; NASEM, 2017）。后果：不做排行、连胜、经验值；路线终点是真实的人或组。

## 4. 概念模型
### 4.1 隐喻：备赛，先选项目
- 机会是赛历；竞争地图是球探报告；边清单是你的身体条件；生态位是你选的项目和位置；定位陈述是你报名时写的「我为什么能赢这一项」；研究思维层是训练；作品是有裁判的成绩；账本是训练日志；学生的 Agent 是他带来的器械和陪练；我们的模型是裁判席；学长学姐与小组是队友。
- 为什么：外在动机正当、截止驱动；先选项目再练，是这群人最缺的一步；没人能替你上场，不代写自然；教练会把人送进队伍，交给真人自然。「备赛」只是设计内部隐喻，UI 不写「比赛」，避免把科研说成竞技。

## 5. 核心交互循环
### 5.1 节奏与触发

| 层 | 触发 | 时长 | 落到的一件事 |
| --- | --- | --- | --- |
| 每日 | 学生设定的一个时刻（可关） | ≤10 分钟 | 分拣 5–8 篇新论文 · 看雷达变化 · 一次定位微调 |
| 每周 · 周一 | 固定 | 5 分钟 | 从 5 个候选重活里选 3 个排进时段 |
| 每周 · 平日 | 学生主动 | 20 分钟–2 小时 | 做一件重活（卡、矩阵论证、画布、测试、套磁准备） |
| 每周 · 周日 | 固定 | 10 分钟 | 回顾交付、小组互评一份、更新组合 |
| 事件 | 评阅完成 | — | 改一处再交，或进下一件 |
| 事件 | 关注的机会 ≤14 天截止 / 拥挤度换档 / 名额变化 | — | 出现在当天雷达里，不另发通知 |
| 事件 | 联系后 14 天无回复 | — | 一次跟进建议或标「没回复」 |
| 事件 | 7 天无交付 | — | 一条安静提示：最小动作 + 影响哪个截止，或暂停目标 |

- 通知：默认每天至多 1 条（每日情报时刻）+ 每周至多 2 条事件，学生可再调低（打断提高速度也提高压力，Mark, Gudith & Klocke, 2008；calm technology，Weiser & Brown, 1996）。
### 5.2 首次（≤15 分钟）
- 表单式建档：目标类型、方向（可多选或「不确定」）、目标学期、每周小时；边清单七类勾选与短填（贴简历 / GitHub 链接可抽取为自述条目）；选每日情报时刻；选你用的 Agent（决定简报格式，可不选）。
- 输出：地图上标出你关注方向的拥挤度（数据不足时如实写）+ 一张示范卡 + 今天的动作「照着示范填一张提示卡」+ 一个空的定位陈述模板（等第一张卡过线后可引用）。
### 5.3 每日（≤10 分钟，可跳过）
- ①分拣（约 6 分钟）：从工具包对应 arXiv 分类的当日新论文里，规则按关键词过滤、我们的模型重排，取 5–8 篇；只显示标题与摘要原文前两句，不给 AI 摘要——分拣本身就是练品味。每篇「留 / 过」+ 一行为什么（≤30 字）；「留」进阅读队列。
- 品味校准：学长学姐可分拣同一批（供给侧贡献），学生分拣后才显示他们的选择，避免锚定；30 / 90 天后回看「你留下的论文后来怎样」（引用数、代码仓星数、是否进了工具包），只给自己看。带反馈的预测训练能提高判断准确度（Mellers et al., 2014）；引用数只是参照，不是品味的标准答案。
- ②雷达（约 2 分钟）：关注的机会新开放、截止变化、名额变化、拥挤度换档；只列变化，没有变化写「无变化」。
- ③定位微调（约 1 分钟）：一个结构化问题，二选一或一句话，如「今天留下的论文碰到你的边『粤语母语』，加入候选生态位？」「新的已证明条目能不能强化你的 Y？」。
- 不做连续天数，漏几天不提示；形成习惯的中位时间约 66 天、偶尔漏一次影响不大（Lally et al., 2010）。
### 5.4 每周
- 周一排 3 件重活（超出周预算提示，考试周自动减量）；平日：今日 → 工作台 →（可选）「交给你的 Agent」→ 回工作台填产物、导入决策日志 → 规则评阅、模型核对 → 未过线改一处 → 过线进账本，可被定位陈述引用；周日回顾与互评，更新「冲 / 稳 / 保」。
### 5.5 交完一件作品
- 只有过线 / 未过线；未过线主按钮是「改这一处」。现在的「进入下一节点」不论过没过都放行，要改。过线后账本写「已证明：能做 X（作品 v2）」，今日与定位页随之变化。
### 5.6 从作品到定位到联系
- 第三张卡过线后出现矩阵；学生选格写三句论证 → 问题 → 画布 → 学长学姐评「值不值得做」→ 定位陈述 X 指向该格或开放问题、Y 引用这些卡与测试 → 套磁准备台 → 看板（同时 ≤3）。
### 5.7 卡住、掉队、换方向、回来
- 卡住了：选类型 + 一句话 → 降一级 / 一条核对过的资源 / 带模板问人；同处卡三次只给「问人」。
- 7 天无交付：一条安静提示 + 「暂停目标」；考试周自动减量。
- 换方向：显示带得走的已证明条目与边、留下的方向专属作品；地图与生态位重算；摇摆的人用「先摸清方向」目标（两周内在两个方向各交两张卡）。
- 两周后回来：第一屏「你不在的两周」（截止、新机会、拥挤度变化、小组交付），「两分钟重排」。
### 5.8 进组之后
- 目标标为「达成」，切到轻量模式（组会前的卡、本研 / 大创申请复用画布与定位陈述）；邀请成为学长学姐：组卡、工具包核对、分拣参照、画布评审，贡献署名。产品承认「你已经有真导师了」。

## 6. 信息架构与导航
- 五个标签：今日 / 定位 / 研读 / 机会 / 作品（手机底部五标签；现在顶栏横排六个，390 宽已挤）。账本在头像菜单「我」（账本、建档修改、我的 Agent、隐私与导出），每个证据片一键直达。
- 全屏工作台（卡、论证、画布、测试、陈述、交、评阅、改）从今日、定位、研读打开，不占导航；顶栏固定「交给你的 Agent」与「导入」两个接口。每个机会、作品、作品集、组卡、工具包都有稳定链接。
- 为什么是这五个：今天做什么（今日）→ 站在哪、凭什么（定位）→ 怎么做实（研读）→ 敲哪扇门（机会）→ 拿得出什么（作品）。

| 现在 | 去向 | 理由 |
| --- | --- | --- |
| 今日 | 今日（每日情报 + 本周主动作） | 每日层落在这里 |
| 画像（对话 + 核对） | 建档表单 + 边清单（定位）+ 账本 | 不聊天；画像变成边与证据 |
| 方向（六棵树 + 主干） | 定位（地图、生态位、时间线、组合）+ 研读（六步阶梯与参考地图） | 主干六步是「做实」的路径，选哪条路是定位的事 |
| 任务 | 工作台（非导航） | 执行面不是目的地 |
| （无） | 研读（工具包、阅读队列、卡、矩阵、问题、画布） | 降本引擎 |
| 项目 · 找项目 | 机会（组、计划、竞赛）；公开练手项目 → 画布「最小测试」候选 | 先有问题再挑试验场 |
| 项目 · 我的项目 / 记录 | 作品 / 账本 | 合并 |
| 多画像 | 多目标（≤3，冲 / 稳 / 保） | 同时追几个目标，不是「几个我」 |

## 7. 关键界面
四张线框：今日（每日情报）、定位（竞争地图 + 定位陈述）、阅读卡（双窗口）、作品集。每个界面写：要完成的事 · 优先级 · 状态 · 规则决定什么 / 模型做什么。
### 7.1 今日 · 每日情报
- 要完成的事：10 分钟内完成分拣、看清变化、推进一次定位，然后知道本周的重活是哪一件。
- 优先级：分拣 > 雷达变化 > 定位微调 > 本周主动作（带证据片与所服务的目标档位）> 本周进度。
- 状态：工具包未覆盖你的方向 → 分拣区写「这个方向还没有工具包」并给「先摸清方向」入口；当日 arXiv 无新论文（周末）→「今天没有新论文」；雷达无变化 →「无变化」；评阅中 → 主动作卡写「评阅中」；模型不可用 → 分拣按规则排序，标「规则」。
- 规则决定：分拣候选（分类 + 关键词）、雷达条目、微调问题的类型、主动作；模型只重排分拣候选并给一句理由（必须指向工具包关键词或矩阵列），以及在规则选出的前 3 个动作里重排。

### 7.3 研读 · 阅读卡（工作台，双窗口）
- 要完成的事：把一篇论文读成一张别人能核对、并能被定位陈述引用的卡。优先级：原文（左，可选中）> 卡（右，六栏）> Agent 建议区 > 核对结果。
- 交互：在原文里选中一段 → 「引为证据 / 引为局限」，引文与页码自动进栏；主张与「我会改什么」只能学生写。状态：抽取失败 → 手填页码，标「未自动定位」；引文对不上 → 红框「原文里找不到」。
- Agent 建议区：每条一个虚线框，状态「未核实 / 已核实 / 原文里找不到」，学生必须逐条「采纳 / 改 / 拒」才能交；只能学生写的栏若与导入的 Agent 文本高度重合，标「与 Agent 输出重合」，该栏不计过线。

- 手机：原文与卡分两个标签页，长按选中引用；首张卡建议在电脑上做。
### 7.4 研读 · 矩阵、问题、画布（无线框）
- 矩阵：行 = 论文、列 = 维度，空格 / 冲突 / 空列由规则标出；卡少于 3 张时显示示范矩阵；选中格子写三句论证；模型只就学生选中的格子提一个问题。手机改为「按维度看」的卡片列表。
- 问题阶梯与画布：三格句式与六栏画布，「已知」只能插入自己的卡、「缺什么」只能插入格子；引用的卡被改成未过线时标「依据变动」；学长学姐评审排队状态可见。
### 7.5 机会、组卡与看板（无线框）
- 列表优先级：收不收低年级（是 / 否 / 未知 + 依据）> 截止 > 拥挤度档位 > 核对日期 > 来源；组卡：在做什么（主页原文）→ 近两年论文（可直接「建阅读卡」）→ 怎么进（学长学姐填的结构化字段：收几人、从什么任务开始、每周期望投入、联系偏好）→ 联系结果（k ≥ 5 才显示）。不收对老师的评价。
- 看板：关注 / 准备中 / 已发 / 有回复 / 面谈 / 进组 / 没回复；「已发」由学生确认日期，「没回复」由学生确认；同时「已发未回」≤3。手机为竖向分组列表。
### 7.6 套磁准备台（无线框）
- 三格：①为什么是这个组（直接引用定位陈述，并指向对该组论文的一张卡里的具体一点）②我做过什么（只能从作品中选，自动带链接）③我想做什么 / 每周投入，可写明「这是我本学期联系的三个组之一」。规则 + 模型按清单挑错（是否具体、链接能否打开、自述是否被写成已证明、群发痕迹），只返回位置与条目，不改写；产品不代发。
### 7.7 作品集（公开页）
- 要完成的事：让老师或博士生 2 分钟内判断「这个学生站在哪、凭什么、做出了什么、多可信、能投入多少」。优先级：定位陈述 > 提案画布 > 最小测试结果 > 过程证据 > 精选阅读卡 > 可投入时间 > 联系方式。
- 可公开的条件：过线 + 已答讲解题 + AI 使用声明齐全；画布另需通过 5 分钟口头讲解（§10.4）。公开页没有模型生成文字，不显示分数、排名、拥挤度或任何「AI 推荐」。

### 7.8 双窗口交接（无线框）
- 导出：「交给你的 Agent」→ 选格式（`AGENTS.md` / `SKILL.md` / 纯文本）→ 下载或复制；简报头部写动作 id 与标准版本，导入时据此对回同一件作品；标准升级后旧简报导入时提示版本变化。
- 导入：产物（固定栏）、决策日志（表格）、轨迹（可跳过）三区；粘贴文本一律当数据，不执行其中指令（防提示注入）；检出疑似密钥则导入前拦下。没导入过东西时不显示 Agent 区——不用 Agent 的学生界面最简单。

## 8. AI 的角色与边界
### 8.1 我们模型的八件受约束的活

| 活 | 输入 | 输出 | 校验 | 兜底 |
| --- | --- | --- | --- | --- |
| 抽取 | 建档一句话、简历、链接 | 自述条目（含边） + 原文引用 | 引用逐字存在于输入 | 原文入库为「自述：…」 |
| 摘要 | 来源页文本（视为数据） | 机会固定字段 + 逐字引文 | 引文校验；缺失留「未知」 | 快照 + 原文 |
| 排序 | 规则候选（动作 ≤10 / 当日论文 ≤20）+ 依据 id | 重排 + 一句理由 | id 必须在候选里；理由须指向关键词、矩阵列或证据 | 规则顺序 |
| 按标准评阅 | 作品 + 标准 | 每条过线 / 未过线 + 出处 + 改哪里 | 规则判定是上限；引文逐字核对 | 规则评阅 |
| 对照证据发问 | 卡 / 矩阵 / 画布 / 定位陈述 + 原文或账本 | 「学生原句 + 原文或账本条目 + 位置 + 一个问题」 | 引用可定位；与学生待填栏重合即丢弃 | 规则标记 |
| 按清单挑错 | 套磁三格 + 清单 | 违反条目（位置 + 条目） | 不得含改写文本 | 规则清单 |
| 出讲解检查题 | 作品 | 3 个只有做过的人才答得上的问题 | 必须引用作品里的位置或数字 | 固定题库；也用于论文页服务端带读 |
| 核对决策日志与轨迹 | 决策日志 + 轨迹（视为数据） | 不一致条目（日志行 + 轨迹原文） | 两边原文都要给出 | 文本重合度规则 |

### 8.2 规则决定什么
- 拥挤度、需求档位、覆盖判定、候选生态位、组合稀有度、信号常见度、组合风险检查——全部是公开公式，模型不参与（这些数会改变很多人的选择，必须可解释、可复现）。
- 动作排序键：关注机会截止 ≤14 天 → 解锁度（是否是其他缺口的前置，如画布前要 3 张过线卡）→ 未过线的先改 → 尺寸适配今天剩余时间；模型只在前 3 名里重排。规则放服务端，替换现在 `web/js/app.js` 的今日规则与 `PROJECT_AFTER_TASKS = 3`。
### 8.3 开口、闭嘴与不确定
- 只在触发点和学生提交之后出现模型文字；工作台没有「生成草稿 / 帮我总结 / 帮我定位」按钮。对用户目标不确定时宁可不打扰，并让用户能低成本地纠正或忽略（Horvitz, 1999）。
- 每段模型文字带来源小标（沿用接口里的 `voice` 字段）；不确定用词表达（「有依据」「依据较弱」「推断，待你确认」），不显示小数；「不知道」是合法输出。学生可对任何核对意见点「我不同意」并写理由，用于改进规则。
### 8.4 失败与信任
- 模型超时或解析失败 → 规则结果（已有）；评阅中途失败 → 先出规则评阅，标「模型核对未完成」；每次调用记 {任务, 模型, prompt 版本, 校验是否通过, 耗时}，校验失败率作周指标。每周随机抽 5% 的模型核对由学长学姐复核。首次使用说明模型做什么、不做什么（Kocielnik, Amershi & Bennett, 2019）。
### 8.5 学生的 Agent
- 不是我们的组件：我们不调用它、不读它的账号或电脑，只接受学生主动导出、导入的内容；它的一切输出都是不可信输入，事实（组名、截止、名额、数据集）以我们的数据为准，冲突时标出；简报里的诚信规则是请求不是保证，保证来自评阅核对与真人讲解（§10.4）。
### 8.6 永远不做
- 不聊天；不替学生读、写卡、填矩阵、出问题、写画布、写定位陈述或套磁信；不给学生「你的最佳生态位」；不编造机会、论文、引文、老师、截止、名额；不预测「你能不能进 X 组」；不评价老师或学生本人；不显示任何个人的目标；不用 AI 检测器判作弊（对非母语写作者有偏差，Liang et al., 2023）；不监考、不录屏、不记键盘、不强制附轨迹。

## 9. 用户模型：可见、可改、可解释
- 三类条目：已证明（由过线作品支撑，不衰减，标准升级后标版本）、自述（建档、边清单、导入）、推断（默认待确认，确认前不参与排序与地图）；现有 `source: declared | inferred | behavior` 正好对应。
- 条目写「能做什么」：把现在写回的「完成微任务《…》：提交了 155 字的记录」改为「已证明：能在论文里定位作者自述的局限并据此提出可检验的改动（阅读卡《…》v2）」。会用 Agent 也是可证明的技能（例：「能让 Agent 挑错而非代写，并拦下其编造的引用」）。
- 证据可点开到原话、作品、评阅引文；可查「这条被哪条建议、哪份定位陈述用过」。兴趣类 60 天无新证据显示「可能过时」（现规则 ×0.9/30 天，界面换成文字）；目标过截止转「待你决定」。
- 改与删：可改（标「本人修改」）、可删（软删 30 天可恢复，之后由学生发起永久删除）、可导出 JSON。
- 隐私分层：私有（默认）/ 小组可见（选定作品与本周交付）/ 公开（作品集）。目标、边清单、联系记录永远不以个体形式出现在任何别人能看到的地方；进入地图的只有聚合档位，k ≥ 5（k 匿名，Sweeney, 2002）、滞后一周、覆盖不足不显示；订阅论文全文只本人可用。

## 10. 反馈与评价
### 10.1 三个问题（Hattie & Timperley, 2007）
- 去哪：动手前看到标准、示范，以及这件作品在定位与目标里的位置（「这是你 Y 的第 2 条证据」「Z 组敲门砖第 1/3 件」）。
- 现在怎样：逐条过线 / 未过线 + 出处（作品原句、论文原句与位置）。下一步：只指一处，按钮就是「改这一处」。
### 10.2 标准注册表
- 内容：阅读卡、矩阵论证、问题阶梯、提案画布、最小测试（复现报告）、定位陈述、套磁清单、决策日志，加上任务 4 每步「做完怎样算过了」和任务 3 五条；各带版本与签认人（目标：每个标准至少一位北大老师或博士生签认）。
- 判据可核对，例：阅读卡「局限栏至少一条引文出自论文的局限 / 未来工作段」；定位陈述「X 指向一个开放问题或格子，Y 至少一条已证明条目，且 Y 不全由该池子里『常见』的条目构成」。「值不值得做」不写成规则、不交给模型：学长学姐或助教用三档（值得 / 可以但要收窄 / 先别做）+ 一句理由评，署名。
- 规则先查、模型再判、规则为上限、引文逐字核对——任务 3 已做对，推广到所有作品类型。去掉界面上的 0–100 分（`Feedback.score`）与空泛的 `encouragement`，换成「k / n 条过线」和「比上一版多过线 1 条」。
### 10.3 改的循环
- 每次提交是一个版本；未过线不阻断做别的，但阶梯、矩阵、定位陈述与作品集只认过线版本；第三次未过线建议降档或问人。
### 10.4 评判断，不只评产物（学术诚信嵌在流程里）
- 前提：学生有 Agent，产物能被代做，所以评阅对象扩到判断与理解；让作假变贵、让诚实的过程变值钱。
- 引文定位拦下编造的引用；只能学生自己写的栏：卡的主张与「我会改什么」、矩阵三句论证、问题阶梯、画布的「缺什么」与「预期与证伪」、定位陈述；其余栏可采纳 Agent 产出，但须在决策日志登记。
- 决策日志评阅：列出 Agent 的主要建议并逐条表态，拒绝要有指向原文、数据或标准的理由；评判断质量，不奖励拒绝条数。附轨迹时由模型找日志与轨迹的不一致，不一致不判作弊，只让该栏不计过线，并只在学生自己的页面列出。
- 理解检查不监考：每件作品 3 个讲解题（可被 Agent 代答，作用是自我解释的学习收益，Chi et al., 1994，并增加作假成本）；画布进作品集前由学长学姐或同伴做 5 分钟口头讲解，这是唯一的硬关口。
- 过程可信度标签（学生自选是否公开）：「引文已核对」「附决策日志」「附真实轨迹」「通过口头讲解」；不显示负面标签。AI 使用声明结构化填写，与决策日志合并展示。
### 10.5 同伴评阅
- 小组每周互评一份，只能用同一标准：选一条标准 → 引作品原文 → 写一条建议，不打分（Topping, 1998）；同组两人读同一篇时矩阵把两人的卡并排；定位陈述互评只回答一个问题：「去掉名字，我能认出这是谁吗？」——认不出说明还不够有区分度。

## 11. 动机与长期使用
### 11.1 立场
- 这群人外在动机强，不需要哄。自我决定论的关键不是「内在 vs 外在」，而是「自主 vs 受控」：被自己认同的外在目标可以持久，被内疚与比较驱动的代价高（Ryan & Deci, 2000）。所以给的是速度、下一步的清晰度、看得见的进展和诚实的位置；比较只在「位置」层面发生（拥挤度、稀有度），从不在「人」层面发生。
### 11.2 机制取舍

| 机制 | 决定 | 依据 / 理由 |
| --- | --- | --- |
| 竞争地图（需求 / 供给 / 势头，按档） | 做 | 这是他们最想要、平台独有的信息；按档、滞后、与边并排以防羊群（Salganik et al., 2006） |
| 组合稀有度与信号常见度 | 做 | 把「和别人比」转成「和别人不同」；只显示三档 |
| 每日情报 ≤10 分钟 | 做，可关 | 小而规律的动作适合形成习惯（Lally et al., 2010）；带反馈的判断训练（Mellers et al., 2014） |
| 就绪度进度（离目标还差几件） | 做 | 越接近目标越努力（Kivetz, Urminsky & Zheng, 2006）；标准参照，刷不了 |
| 下注组合与时机 | 做 | 把焦虑转成可管理的风险结构（Chade et al., 2014） |
| 本周 3 件重活 + 时段 | 做 | 执行意图（Gollwitzer & Sheeran, 2006）；大规模下效果有限，只做轻量版（Kizilcec et al., 2020） |
| 小组（4–6 人，周交付 + 互评） | 做，可退出 | 小池子减少 N 效应带来的动机下降（Garcia & Tor, 2009）；可见的成功同伴做法提高完成率（Davis et al., 2017） |
| 参照轨迹（同意公开的学长学姐时间线） | 做，标 n 与时间 | 同时展示没进组也有收获的轨迹，抵消幸存者偏差 |
| 公开作品集 | 做，默认关 | 展示作品本身，比的是标准 |
| 排行榜、「击败 X% 同学」 | 不做 | 一学期内降低内在动机与成绩（Hanus & Fox, 2015）；精英校里相对位置压低自我概念（Marsh, 1987）；在内卷语境下放大非理性竞争（Liu et al., 2022） |
| 连胜 / 连续天数 | 不做 | 奖励出现而非交付，制造内疚；漏几天不该被惩罚 |
| 经验值、等级、徽章 | 不做 | 游戏化效果取决于设计（Sailer & Homner, 2020），外在奖励削弱对有趣任务的内在动机（Deci, Koestner & Ryan, 1999）；里程碑就是过线作品 |
| 可变奖励、限时稀缺、「X 人正在申请」实时计数 | 不做 | 制造焦虑和抢跑（Roth & Xing, 1994），也会被操纵 |

### 11.3 掉队与回来
- 暂停是正常操作；回来先看「你不在的两周」；不追问原因。每日层漏掉不提示，每周层 7 天无交付才有一条安静提示。
### 11.4 交给真人，不假装是导师
- 每个目标的终点都是人。产品负责让学生带着定位陈述、画布和好问题到人面前：套磁准备台、面谈准备（再读对方一篇论文、写 3 个具体问题）、答疑模板（我在做什么 / 卡在哪 / 已试过什么）。有效科研指导的要素来自真实关系（Pfund et al., 2016; NASEM, 2019），产品不冒充；进组后从主线退场。

## 12. 伦理与风险（围绕野心而不是脆弱）
- 新的军备竞赛：当所有人都在「定位」，定位本身会变成新的内卷（Campbell, 1979 的指标被刷）。对策：定位陈述绑在已证明条目上；「常见理由」检测；不奖励陈述数量与改版次数；作品集最多展示 1 份陈述 + 1 张画布 + 3 件作品。
- 羊群与少数派博弈：地图可能把所有人推进同一个冷门（§1D.8）。对策见 §1D.8；上线后每周看目标集中度，变集中就收紧。
- 抢跑与市场解体：时机建议若只说「越早越好」，会把整个院系的套磁季往前推（Roth & Xing, 1994）。对策：时机绑在就绪点上，不给「最早」激励。
- 操纵需求数据：虚报目标吓退别人。对策：只数有过线作品的活跃目标；每人 ≤3；异常激增人工复核。
- 对组的影响：拥挤度可能被读成「这个组好 / 不好」。对策：只给学生看、只显示需求与已知名额、不做组的排名、不收对老师的评价；组卡更正走「申请更正 + 来源」。
- 压力放大：缺口与拥挤度一直可见可能成为焦虑源。对策：周预算上限、考试周自动减量、每日层可关、不显示任何「别人比你快」。
- 学术诚信：不代写、不替读、引文定位、决策日志、讲解、版本痕迹；不做「论文辅导」「挂名」撮合；学长学姐的试做任务 ≤3 小时、必须是学习任务、不得以署名换劳动。学位法第三十七条把代写、剽窃、伪造列为不授予或撤销学位情形；「论文工厂」用 AI 批量代写（新京报, 2024）。这是对机构的护城河。
- 学生的 Agent 成为代写者：简报挡不住决心作假的人。对策是 §10.4 的组合，并接受残余风险——老师最终还会面谈，产品不假装是监考。
- 监视的边界：轨迹永远可选、导入前剔除密钥、学生决定公开范围、可随时删除；不因没附轨迹降低任何评价。以后的 MCP 授权按类别、可撤销、留日志，写明数据会离开启研。
- 公平：老师回复套磁存在按姓名所示性别与族裔的偏差（Milkman, Akinola & Chugh, 2015）；第一代大学生参与科研更少（Ke et al., 2022）。策略层本身可能让「本来就会算计」的人更占便宜。对策：滩头选缺人脉的人；地图与信号表对所有人同样可见；§15 分人群看选择与结果。
- 提示注入：导入的轨迹、来源页、论文文本都当数据，不拼进会被执行的指令位置；模型输出必须引用原文位置，否则丢弃。
- 版权与来源：订阅论文全文只本人可用；工具包只存元数据与短引文并指明出处（著作权法第二十四条）；只抓公开页面，需登录的校内系统（如本研系统）不抓取。

## 14. 落地路线（按天）
### 14.1 原则
- 先建会积累的结构（地图数据、账本、标准、工具包、引文校验、作品集），最后才碰模型措辞。一个方向、一个子领域打穿：人工智能（信科）+「大模型评测」工具包（论文大多在 arXiv，局限段常讨论数据污染与指标；北大哪些组在做需核对，「未核实」）。
- 写软件便宜，写不快的是人：工具包核对、30–50 个组的数据核对、学长学姐组卡、招募被试——第 1 天就并行开始，由 2 名同学专职。每天傍晚在真学生身上跑一次（哪怕 3 个人），先展示结果再改代码。
### 14.2 单人 + Agent 每天交付什么

| 天 | 交付 | 完成的判据 |
| --- | --- | --- |
| D1 | 阅读卡工作台：原文选中即引用、逐字定位（复用 `submission.py` + 规范化匹配）、示范 / 提示 / 独立三档；由标准生成「交给你的 Agent」简报 | 10 篇 arXiv 论文上实测自动定位率与误报率（先测后宣称）；一条编造引用被拦下 |
| D2 | 服务端账本（`Goal`、`Edge`、`Artifact` 版本，进度迁出 localStorage）+ 建档表单 + 边清单 + 定位陈述编辑器与规则检查 | 换浏览器不丢；陈述能引用 D1 的过线卡 |
| D3 | 机会库种子（人工核对的数据导入）+ 竞争地图 v0（供给 + 势头；需求在覆盖不足时显示「数据不足」）+ 候选生态位表 → **第一条纵切片**：边清单 → 地图 → 定位陈述（引用一张过线卡）→ 作品集首行 | 3 名学生走通纵切片 |
| D4 | 每日情报：按工具包分类取 arXiv 当日新论文、分拣（留 / 过 + 理由）、雷达变化、定位微调问题 | 一名学生 10 分钟内完成；周末空态正确 |
| D5 | 矩阵（格子由卡计算，规则标记）+ 问题阶梯 + 提案画布 + 学长学姐评审（先用表单与通知） | 3 名学生各 3 张卡后看到自己的矩阵 |
| D6 | 作品集公开页 + 看板 + 套磁准备台（规则清单）+ 下注组合检查 + 导入（决策日志 / 轨迹） | 一个演示学生生成可分享链接 |
| D7 | 五标签 IA、关模型全流程测试、需求聚合（k 阈值、滞后、只数有投入的目标）、演示 | 关掉模型能走通；k 阈值单测 |

- 5 人并行：D1–D3 分给三人同时做，约 3 天出 v1，剩下几天全部用于 §15 的 T1–T3。推迟：只读 MCP、日志对照轨迹的模型核对（先用文本重合度）、模型对照原文发问（先规则）、中文 PDF 稳健抽取、第二个工具包、组卡认证（先用邀请码）、外部通知渠道、首页动画、付费。砍掉：聊天、多画像、游戏化、任何「AI 帮你写 / 读 / 找 / 定位」。
### 14.3 演示脚本（也是产品故事）
- 建档与边清单（1 分钟）→ 竞争地图：两个「热」组与一个「数据不足 / 供给 1」的组，学生的组合「罕见」（1 分钟）→ 读一篇论文填卡，引文错误当场标出（1.5 分钟）→ 「交给 Agent」导入建议，一条编造引用被拦、一条被拒并写理由（1 分钟）→ 定位陈述引用这张卡，规则提示「会 Python 在这里常见」（1 分钟）→ 每日情报 30 秒走一遍 → 作品集首行（30 秒）→ T1 / T2 初步结果（1 分钟）。关掉模型重跑地图与陈述两步，证明策略层是结构不是话术。

## 15. 怎么验证
### 15.1 原则
- 先验证会让我们重来的策略层假设（§1A.6），再做可用性；每个测试开测前写下「什么结果会让我们改设计」的阈值。
- 伦理：知情同意、随时退出、数据匿名；不对老师做欺骗性的「假学生邮件」实验；被试回报不与是否进组挂钩；对照组结束后可免费使用启研。
### 15.2 测试清单

| 编号 | 验证 | 方法 | 样本 | 测什么 | 改设计的判据 |
| --- | --- | --- | --- | --- | --- |
| T1 | R1 地图改变选择且不制造扎堆 | 一次 60 分钟的实验课：先写下自己的 3 个目标与理由；随机分组，A 组只看机会库 + 自由用自己的 Agent，B 组再加边清单、竞争地图与候选生态位；然后重写目标。需求用同一批学生事先匿名填的目标聚合（达到 k 才显示），供给与势头用真实数据 | 有野心的大一大二 30–40 人 | 目标落在「热」档的比例变化；盲评学长学姐打的「边匹配度」；组内目标集中度（赫芬达尔指数）A vs B；对地图的信任度 | B 不改变选择：地图降为参考信息，不做主导航；B 改变选择但集中度上升：加强拥堵感知轮换、改为只显示与边并排的档位；B 转向低拥挤且边匹配升高：作为对外主叙事 |
| T2 | R2 定位陈述胜出 | 每人先写一段给目标组的「普通自我介绍」；随机分组，A 组用自己的 Agent 改写 60 分钟，B 组用启研（边清单 + 地图 + 陈述规则 + 至少 1 张过线卡）60 分钟；目标读者盲评成对材料 | 20–24 名学生；目标组的博士生 / 博士后 / 高年级学长学姐 6–10 人 | 成对偏好「更想和谁聊」、区分度、可信度、具体性（报告评审一致性）；「去掉名字能认出是谁吗」 | B 不胜 A：陈述规则没起作用，重做检查项与示范；B 胜在可信度但不胜区分度：加强稀有度与常见理由检测；B 全面胜出：陈述成为作品集与套磁的核心 |
| T3 | R3 每日情报能坚持 | 3 周实地使用，每日层可关 | 15–20 人（与 T5 同批） | 每日完成率、实际耗时中位数、第 7 / 14 / 21 天仍在分拣的比例、关闭原因；分拣与学长学姐选择的一致性趋势 | 耗时中位数超过 10 分钟：只保留分拣；第 3 周多数人停用：改为每周两次的「情报日」；一致性无变化：取消校准回看，只留分拣进阅读队列 |
| T4 | R4 Agent 单独 vs Agent + 启研 | 两周、同一任务：「为一个真实组准备联系材料：定位陈述 + 读其 2–3 篇论文 + 一个一学期可做的问题 + 最小测试」。两组都用自己惯用的 Agent；B 组再加启研；两组都交真实轨迹（研究用，事后删除） | 20–24 人，按方向、经历、Agent 熟练度配对 | ①事实与引文错误率 ②问题质量盲评 ③是不是自己想的（口头讲解 + 轨迹里「让 Agent 下结论」vs「让它挑错」的比例）④定位区分度 ⑤目标是否扎堆 ⑥到「可发送」的用时 | B 只在①占优：价值在数据，优先做 MCP 把数据喂给学生的 Agent；B 在②③不占优：回到示范、标准与简报；B 明显更慢且②③④无优势：砍掉导入与日志摩擦；B 全面占优：对外主叙事 |
| T5 | R5 冷启动与操纵 | 滩头（一个院系 × 一个方向）小组招募上线 3 周；团队成员做红队，尝试虚报目标操纵热度 | 滩头全部用户 | 主要目标达到 k 所需周数；红队能否改变档位 | 3 周达不到 k：需求改为按方向而非按组聚合；红队成功：收紧「有投入」的定义 |
| T6 | R6 / R7 供给与维护成本 | 真实邀请学长学姐写组卡、核对工具包、做分拣参照；团队记录每条数据的人力与 3 周失效率 | 大三以上及研究生 20 人；团队计时 | 完成率、用时、动机访谈；单位数据成本 | 完成率低：字段砍半或由团队 5 分钟访谈代录；成本过高：只维护「确定收本科生」的组 |
| T7 | 引文定位可行性 | 离线：30 篇 arXiv PDF，人工标注 200 条引文 | 团队 | 召回率、误报率 | 误报高：自动定位只作提示，不阻断 |
| T8 | 可用性 | 出声思考：建档 → 边清单 → 地图 → 陈述；每日情报；卡 → 导入 Agent 建议 | 每轮 5–8 人，两轮 | 完成率、错误、用时 | 关键流程完成率低于事先设定的线：重做再测 |
| T9（后期可选） | 老师是否看重作品集与过程证据 | 知情同意的盲评，非门槛 | 老师 / 博士生 10 人 | 愿意回复 / 见面 | 只用于调整作品集版面 |

### 15.3 上线后每周看
- 策略层：目标集中度（赫芬达尔指数）及其变化、落在「热」档的目标比例、陈述中已证明条目占比、「常见理由」触发率、组合中冲 / 稳 / 保的分布。
- 每日层：分拣天数分布、耗时、关闭率、校准一致性；漏斗与结果：激活、W1–W4 留存、作品集外链打开、联系 → 回复 → 面谈 → 进组 / 立项，按人群（第一代大学生、地区、性别）分看。
- 质量：引文自动定位率、模型校验失败率、学长学姐抽查一致率、机会数据过期率、工具包复核日期；伤害：每月一次三题压力与睡眠自评（自愿），上升时检查预算与提醒规则。
