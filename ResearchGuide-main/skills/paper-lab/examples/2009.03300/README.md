# Paper Lab：大规模多任务语言理解评测

这次「实验」只有一篇论文：Measuring Massive Multitask Language Understanding（arXiv:2009.03300）。你不是来写代码的，是来把一篇真论文读懂到能用自己的话复述、能指出它没做什么的程度。全程由你的 agent 带着走：它出问题，你答，它判并追问；它不会替你答。**全部在本地完成，不需要真实 Key。**

这篇论文造了一份横跨几十门学科、从小学到职业考试难度的四选一考卷（后来通称 MMLU），用来测大模型在预训练后到底学到多少知识、会不会用；今天几乎每份大模型发布报告都报它的分数，先读它，才知道「模型考了多少分」这句话背后用的是什么尺子。

## 开始前

在个人仓库根目录打开 Codex（或 Claude Code / DSH），发送：

```text
请完整阅读 paper-lab/2009.03300/AGENTS.md 和 paper-lab/2009.03300/README.md，按顺序带我读完这篇论文。
```

推荐全程在同一个对话中完成。学生读到「目标与提交内容」即可；后续流程由 agent 逐步讲解。

## 目标与提交内容

读完你应能：用自己的话说出作者做成了什么、怎么做的、凭什么（哪个数字）、默认了什么没检验、作者自己承认的局限是什么、你会改哪一处。

提交目录 `paper-lab/2009.03300/` 至少包含：

```text
paper-lab/2009.03300/
├── README.md          # 本文件
├── AGENTS.md          # agent 的规矩与题位（只读）
├── answers.md         # 八道题你的原话 + agent 的判定（最后由 agent 整理，你确认）
└── AGENT_TRACE.md     # 最后复制真实对话或填写真实分享链接
```

不要提交密钥、`.env`、论文 PDF 原文件和 `paper.txt`（写 arXiv 号即可，用时重新取）。

## Agent 执行协议

本 README 是交互式流程，不是一次性任务书。`[AGENT ACTION]`、`[STUDENT ACTION]`、`[REFLECTION]`、`[AGENT STOP]` 只供内部控制，不在正常对话中播报阶段代号。每道题开始前说清这一题考什么、要去哪一节找；学生作答或思考时结束当前回复并等待，不提前出后面的题，不反复问没有新内容的「是否继续」。

Agent 负责取论文、按节出题、判卷、追问、最后整理 answers.md；学生负责读、用自己的话答、提出疑问。Agent 不替学生写任何一道题的答案，也不把判卷标准念出来当提示。

### 思考题答不上来时怎样引导

学生说「不知道」「不会」「直接告诉我」，或答错、答不完整时，**不能直接给出答案或替学生完成推理**：

1. 先问卡在哪，肯定已有的正确部分；把原题拆成一个更小、更具体的问题。
2. 每轮只给一个必要的提示或追问，结合论文这一节的具体句子或一个简单例子；**提出问题后结束回复，等待学生回应**，不在同一条回复里自问自答。
3. 仍答不上来，降低难度，补讲缺的概念，再用小问题检验；可以解释概念，不能把本题结论一次性讲完，不把答案藏在诱导性问句里。
4. 学生形成理解后，请其用自己的话说一遍，再纠正、补充并简短总结。不能只凭「懂了」就认定已经理解。

### 首次讲解：让学生知道为什么读这篇

> [AGENT ACTION]

**这是导入，不是术语速览。** 首次回复必须用自然语言讲出下面每段的实质内容，可调整语气，但不能压缩成名词清单或直接开始出题。

**给学生的开场讲解稿：**

你可能听过「某个大模型考试拿了高分」这种说法，但先要问：考的是哪份卷子？AI 研究里比较模型靠的是「基准」（benchmark）。它和你自己做实验时留出来的「测试集」不一样：测试集只是从数据里留出一部分，检查你自己的模型有没有学偏；基准是整个领域约定共用的一把尺子，题目和打分规则公开固定，谁的模型都能来考，分数直接摆在一起比。尺子一旦被考到接近满分，就再也量不出谁强谁弱。这篇 2020 年的论文，正是在旧尺子快被考满的时候造了一把新尺子；今天的大模型报告几乎都报它的分数，它是读懂「模型有多聪明」的起点。

作者想测的是：模型先在海量网页和书籍上「预训练」（读大量文字、学着接下一个词）之后，到底记住了多少各学科的知识，又能不能拿来解题。以前的基准多考语言技巧，或者考小孩都懂的常识；这篇换成人要专门学才会的科目，从小学数学到法律、医学、历史，全部做成四选一的选择题，难度从入门一直到职业资格考试。

关键在「怎么考」。常见做法叫「微调」（fine-tuning）：先拿某个任务的大量带答案题目把模型再训练一遍，再去考同类题，就像考前反复刷同一套题库。这篇主要用「少样本」（few-shot）：不再训练，只在题目前面摆几道带答案的示范题，让模型照着格式直接作答，更像让一个人凭平时积累去考一份陌生的卷子；作者也拿一个做过微调的模型来对照。除了看答对多少（准确率），他们还看「校准」：模型说自己有八成把握时，是不是真的大约八成答对。准确率问的是「答对没有」，校准问的是「知不知道自己会不会」，两者可以差得很远。

这次你要亲自走四步：先读摘要，抄出作者说本文做成了什么的原话，再用自己的话复述主张；再读引言和方法，说清要解决什么、具体怎么做、默认了什么却没检验；接着读实验，先预测结果，再找出一句撑住主张的带数字原句；最后读讨论和结论，找作者自己承认的不足，提出一处你会改的地方。走完你会留下一份 answers.md（八道题你的原话和判定）和一份真实对话记录。我负责贴原句、每次只问一道题、判过没过并说明缺什么；你负责读原文、用自己的话答、随时提问。我不替你写答案，卡住时会把问题拆小。准备好了吗，还是先问点什么？

讲解稿最后一段已含四步路线（读摘要答主张 → 读方法答做法与前提 → 读实验答证据 → 读结论答局限与改动）和产物。**首次回复到「准备好了吗，还是先问点什么」为止，不再追加别的问题。**

**开场自检（内部执行，不播报）**：学生此时应知道这篇论文解决什么问题、作者大致怎么做、这次实验里自己要做什么、agent 不会替他答。缺一项先补讲。

## 任务 1：主张（摘要）

> [AGENT ACTION]

带学生读摘要（agent 把摘要贴出来，不翻译整段，只解释术语）。然后依次出 q_claim_quote、q_claim 两题，题面、提示见 AGENTS.md，每题一轮。

> [STUDENT ACTION]

学生读摘要，先抄一句作者说本文做成了什么的原话，再用自己的话（10–160 字）说作者声称做成了什么。

> [REFLECTION]

你复述的主张里，哪部分是「造了什么」，哪部分是「发现了什么」？能分开各说一句吗？

> [AGENT STOP]

告诉学生下一步是读引言和方法，弄清「要解决什么、怎么做的」。

## 任务 2：问题与做法（引言、方法）

> [AGENT ACTION]

指到引言的问题陈述段和方法的核心段（贴原句，不概括成结论）。依次出 q_problem、q_method、q_assumption 三题，每题一轮。

> [STUDENT ACTION]

学生用自己的话答：这一节在解决什么问题；一句话他们怎么做的（写步骤）；作者默认成立却没检验的一件事。

> [REFLECTION]

如果允许模型考前刷同类题库，这份考卷原本想测的东西还测得到吗？你写的那个前提一旦不成立，哪条结论会先站不住？

> [AGENT STOP]

告诉学生下一步是看实验，找一个真正撑住主张的数字。

## 任务 3：证据（实验）

> [AGENT ACTION]

先请学生**预测**：看了方法之后，猜主要结果会是什么量级、作者最想强调哪一个对比；agent 不公布实际数字。等学生预测后再带学生读实验节，出 q_evidence。

> [STUDENT ACTION]

学生写下预测；读实验节；抄一句带数字、能支撑主张的原句。

> [REFLECTION]

你抄的数字撑住的是摘要里哪一句主张？对照读实验前的预测，你差在哪里？

> [AGENT STOP]

告诉学生最后一步是看作者自己承认的局限，并想一处自己会改的地方。

## 任务 4：局限与改动（讨论、结论）

> [AGENT ACTION]

指到局限/讨论段。依次出 q_limit、q_change。q_limit 在论文没有局限段时可跳过（AGENTS.md 已标）。

> [STUDENT ACTION]

学生抄一句作者承认没做到或可能不成立的话；写自己会改的一处（改什么、改了能检验什么）。

> [REFLECTION]

你提的改动，用作者已经公开的题目和数据能不能直接检验？如果不能，还缺什么？

> [AGENT STOP]

这一题的反思问过、学生回过，才说明接下来是总评与整理 answers.md。

## 提交与结束

> [AGENT ACTION]

四个任务的反思都问过、学生都回过之后，给 ≤200 字总评：过了几题、最值得再看的一节。问学生要不要整理 `answers.md`；学生同意后写入：每题题面、学生原话、判定（通过/没过）与一句理由，不改写学生的话。提交 `paper-lab/2009.03300/` 下的 README.md、AGENTS.md、answers.md（提交信息 `paper-lab: 2009.03300 answers`）。

> [STUDENT ACTION]

新建空的 `AGENT_TRACE.md`，把本次对话复制为 Markdown 粘贴进去（或填写真实分享链接）；检查里面没有密钥。

> [AGENT ACTION]

确认 AGENT_TRACE.md 是真实对话而不是总结；只含它的最后一次提交（`paper-lab: 2009.03300 trace`）。PR 标题和正文用中文，写清论文号、姓名、学号。经学生授权才代发 PR，否则指导其提交。

> [AGENT STOP]
